Configurar banco de dados

O Gráfica OS guarda os dados em um banco MongoDB. Informe onde ele está.

A conexão está definida pela variável MONGO_URL (arquivo .env da pasta do projeto). Para usar esta tela, remova essa linha do .env.

MongoDB Atlas (nuvem)

No site do Atlas, em Connect › Drivers, copie a string e troque <password> pela senha do usuário do banco.

Neste computador

Instale o MongoDB Community Server como serviço.

Chave de segurança

Protege os CPFs e CNPJs no banco. Todos os computadores da gráfica precisam da mesma chave.

Este banco já tem dados de outro computador. Importe o arquivo de chave exportado lá pelo administrador.
